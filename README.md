# fluffy-assets

Archivos estáticos de la tienda Fluffy (fluffy-pets.com) que Tiendanube no permite subir al tema.

- `mascotas/` — Puma y Pancho animados, con fondo transparente: `.webm` (VP9) para Chrome/Firefox/Android y `.mov` (HEVC) para Safari/iPhone.

Se sirven con jsDelivr: `https://cdn.jsdelivr.net/gh/contactof281/fluffy-assets@<tag>/mascotas/puma.webm`
- `marca/fluffy-logo.svg` — logo de Fluffy vectorizado (azul #004AAD), para el logo grande del footer.
- `michipad/mp-*.webp` — fotos de las 4 tarjetas "Por qué lo eligen" de la ficha del MichiPad (antes PNG de Boostify).
- `michipad/videos/` — 7 videos del carrusel de la ficha del MichiPad (MP4 540×960, H.264) con su portada WebP del mismo nombre.

Ojo: jsDelivr no sirve repos de GitHub de más de 50 MB ni archivos de más de 20 MB.
